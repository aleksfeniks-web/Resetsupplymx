# Skill: Promotion Builder

## 1. Propósito
Diseñar promociones comerciales rentables basadas en inventario disponible y complementariedad.

## 2. Cuándo Usar Esta Skill
Al ejecutar /promo o cuando el usuario pida ideas para elevar ventas o liquidar exceso de stock.

## 3. Datos Requeridos
Productos con exceso de inventario, márgenes actuales, productos complementarios y precios de lista.

## 4. Procedimiento Paso a Paso
1. Identificar productos con rotación lenta o alto margen.
2. Asociar un accesorio o producto de alta demanda (ej. limpiador + microfibra).
3. Calcular el precio del paquete asegurando un margen global >= 30%.
4. Diseñar el copy comercial y la vigencia sugerida.

## 5. Formato de Respuesta
Nombre de la promoción, productos incluidos, precio regular vs precio promocional, ahorro para el cliente, margen resultante y copy para mostrador/web.

## 6. Reglas de Seguridad
Acción RECOMMEND. La activación en web o POS requiere confirmación WRITE.

## 7. Posibles Errores y Manejo de Contingencias
Generar promociones que erosionen el margen por debajo del umbral mínimo permitido.
