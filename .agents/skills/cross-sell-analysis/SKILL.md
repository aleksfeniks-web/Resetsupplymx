# Skill: Cross-sell Analysis

## 1. Propósito
Detectar patrones de compra donde productos complementarios no están siendo adquiridos conjuntamente.

## 2. Cuándo Usar Esta Skill
Cuando se busquen oportunidades de venta cruzada en mostrador o tienda web.

## 3. Datos Requeridos
Listado de tickets con detalle de artículos (items) vendidos juntos.

## 4. Procedimiento Paso a Paso
1. Analizar combinaciones de productos en el mismo ticket.
2. Identificar productos que se compran aislados pero requieren accesorios (ej. Sintra sin aplicador, cerámico sin microfibra de nivelación).
3. Calcular la tasa de penetración de complementos.
4. Formular la regla de sugerencia para el cajero del POS.

## 5. Formato de Respuesta
Patrón detectado, tasa de compra cruzada actual, oportunidad económica estimada y guion para cajero/POS.
