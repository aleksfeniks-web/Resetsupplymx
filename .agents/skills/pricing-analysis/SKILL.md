# Skill: Pricing Analysis

## 1. Propósito
Evaluar la competitividad y coherencia de los precios de venta frente a márgenes y volumen.

## 2. Cuándo Usar Esta Skill
Cuando se evalúe subir o bajar precios, lanzar ofertas o revisar el margen de un producto específico.

## 3. Datos Requeridos
Precio de lista actual, precios con descuento, costo de adquisición y volumen histórico de ventas.

## 4. Procedimiento Paso a Paso
1. Comparar precio actual vs costo mayorista para determinar margen unitario.
2. Comparar elasticidad: evaluar si productos con menor precio venden significativamente más volumen.
3. Identificar productos con margen superior al 45% (candidatos a promociones) y productos con margen inferior al 25% (candidatos a ajuste de precio).

## 5. Formato de Respuesta
Análisis de precio actual, margen unitario en $, margen en %, comparación de volumen y recomendación de ajuste.

## 6. Reglas de Seguridad
Acción RECOMMEND. Cambiar precios en la web requiere autorización WRITE directa.

## 7. Posibles Errores y Manejo de Contingencias
Precios en cero o no definidos en productos variantes, promociones con vigencia vencida.
