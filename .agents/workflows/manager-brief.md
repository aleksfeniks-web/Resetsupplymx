# Workflow: Resumen Ejecutivo de Atención Prioritaria

- **Comando Directo**: `/manager-brief`
- **Descripción**: Responde "¿Qué necesita mi atención hoy?" consultando a todos los agentes especializados.

---

## Procedimiento de Ejecución
1. Consultar a Inventory Agent para detectar desabastos o riesgos de quiebre de stock inminentes.
2. Consultar a Commerce Agent para identificar pedidos web pendientes de guía de envío y facturas SAT sin timbrar.
3. Consultar a CRM Marketing Agent para oportunidades de reactivación de clientes inactivos.
4. Filtrar y jerarquizar los hallazgos por impacto económico y urgencia temporal.
5. Limitar la respuesta ejecutiva estrictamente a:
   - Máximo 3 ALERTAS críticas.
   - Máximo 3 OPORTUNIDADES comerciales.
   - Máximo 3 ACCIONES RECOMENDADAS priorizadas.

---

## Políticas y Reglas de Seguridad
Acción READ / RECOMMEND. Enfoque 100% directivo y libre de ruido operativo.
