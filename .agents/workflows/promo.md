# Workflow: Generador de Promociones Rentables

- **Comando Directo**: `/promo`
- **Descripción**: Diseña bundles y ofertas promocionales para dinamizar ventas protegiendo el margen.

---

## Procedimiento de Ejecución
1. Analizar el catálogo en busca de productos con stock alto o días de inventario > 45.
2. Evaluar el margen comercial de dichos productos para conocer el espacio de descuento disponible.
3. Seleccionar productos complementarios de alta rotación (ej. limpiador multiusos + microfibra de secado).
4. Calcular el precio del paquete (bundle) asegurando que el margen bruto resultante sea >= 30%.
5. Verificar el historial de ventas para asegurar que la combinación sea atractiva para los clientes.
6. Generar el nombre de la promoción, ahorro monetario para el cliente y copy publicitario para POS y redes sociales.
7. Nunca recomendar descuentos que generen margen negativo (< 0%) sin autorización expresa.

---

## Políticas y Reglas de Seguridad
Acción RECOMMEND. La activación de precios o banners requiere autorización WRITE del usuario.
